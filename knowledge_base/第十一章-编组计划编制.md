## 任务与定位

「技术站列车编组计划的任务是对技术站发出的各支车流，按照去向分别编组成不同到站、不同种类的列车，即把技术站发出的各支车流纳入技术站编发的各支列流中去。」

> 与第四章的关系：第四章是**微观调车作业计划**（给定车列后生成摘挂钩序列）；第十一章是**宏观车流组织计划**（决定哪些车流合并、开哪些列流）。本项目的 `target_order`（目标编组顺序）的「依据」正来自列车编组计划。

## 一、编制列车编组计划的主要因素

### 技术站间计划车流（车流归并）

「由重车车流表到技术站间车流表的过程实质上是车流归并的过程。」归并按上、下行分别进行：
- 技术站发出的车流 = 本站产生的 + 本站后方区段各站及衔接支线产生的 + 到达本站解体的装车地直达列车中的远程车流；
- 技术站到达的车流 = 本站到达的 + 衔接支线上各站到达的 + 本站与前方相邻技术站间所有各站到达的。

技术站间车流表和车流梯形图是编制技术直达列车和直通列车的基础资料。

### 货车集结车小时

- 某支列流一昼夜集结车小时消耗与该支列流平均列车编成辆数 `m` 成正相关，**与吸收的车流量无关**。
- 编开一个列车到达站一昼夜消耗 `T集 = cm`。集结参数 `c`：区段站 8~10 h，编组站 10~11 h。
- 某方向一昼夜编 `k` 支列流，总消耗：

  `T集总 = k·T集 = kcm` （式 11.1）

### 货车无改编通过技术站的节省时间

- 无调中转车：「只在到发线上进行到发技术作业即随原列车继续运行」的货车。
- `t节` = 货车无改编通过较之改编所节省的时间。
- 改编作业当量 `r车` = 调机平均改编 1 辆货车所折合的车小时数：

  `r车 = e机时 / (N调 · e车时)` （式 11.2）

- 平均每车无改编通过节省：

  `t节 = t有 − t无 − t集 + r车` （式 11.3）

- `t节` 经验取值：自动化/机械化驼峰编组站 2~3 h；非机械化驼峰编组站 3~4 h；区段站 4~7 h。

## 二、编制单组列车编组计划的基本原理

### 车流组织两原则

1. **同一支车流不拆散原则**：「不应当将同一支车流的车流量分离出来，分别与不同的车流合并，纳入几支不同的列流中。」
2. **车流接续归并原则**：长程车流在技术站改编后「成为该技术站发出的车流的一部分，与该站相同到站的车流合并开行」。

### 编组方案表示法

- 数字=车流到达站；`+`=车流合并开行；`,`=车流不合并；`;`=各技术站方案分隔。
- 例：`A3` 站 `N30,N31,N32` 都单开 → `0,1,2`；`N30` 与 `N31` 合并、`N32` 单开 → `0+1,2`。
- 方向上方案写法：`2+1,0;1+0;0`。

### 单组列车编组方案数（组合爆炸）

直线方向全部编组方案数：技术站数 2→9 时分别为 1, 2, 10, 150, 7800, 1583400, ≈1.39×10⁹, ≈5.75×10¹²。相邻车流合并的方案数为 `2^(n-2)`。

缓解方法：**分阶段计算法**，把全路划分成多个方向，每个方向只含少数几个主要编组站（**支点站**）。

### 总体思路（优化算法三类）

1. **穷举法（绝对计算法）**：对所有编组方案逐一计算车小时总消耗，最小者为最优。
2. **筛选法**：用判别条件排除不利方案、精简方案数。代表：表格计算法。
3. **数学规划法**：整数规划、动态规划、二次 0-1 规划、网络分析等。

## 三、单组列车编组计划的编制

### 绝对计算法

目标函数（非短途列流只算集结消耗 + 途中改编消耗）：

`min F耗 = Σ_{i∈Z} ki·T集^i + Σ_{j∈G} N改^j·t节^j` （式 11.8）

显然不利方案两种情况：
1. 远程车流与短程车流合并时额外增加改编作业次数；
2. 合并时改编次数不变，但在 `t节` 较大的支点站改编。

### 表格计算法（重点，目标相反但结果一致）

表格计算法求**车小时总节省最大**：

`max F节 = Σ_{w∈W} N通^w·t节^w − Σ_{i∈Z} ki·T集^i` （式 11.10）

三个判别条件：

| 条件 | 含义 | 公式 |
|---|---|---|
| **绝对条件** | 必须开行直达列流 | `Nij · min{t节^k | k∈K} ≥ T集^i` （式 11.11） |
| 绝对条件推论 | 不在 k 站改编 | `Nij·t节^k ≥ T集^i` （式 11.12） |
| **必要条件** | 单开才可考虑 | `Nij·Σ_{k∈K} t节^k ≥ T集^i` （式 11.13） |
| 必要条件 | 合开才可考虑（`ΣN` 为合并总流量） | `ΣN·Σ_{k∈K} t节^k ≥ T集^i` （式 11.14） |
| **充分条件** | 长程不与短程合并 | 长程车流在超行区段无改编通过节省 ≥ 始发站集结消耗 |

三者性质（原文）：绝对条件「真正'绝对'」，满足就一定开行；必要条件是单开/合开的前提，满足才可考虑但未必开行；充分条件满足就不应合并，不满足是否必须合并也要比较确定。

**算法步骤**（四步）：
1. 计算所有 `N通·t节` 填入计算表；
2. 确定初始方案：绝对条件画「△」（确定开行）、必要条件画「○」（暂定单开）、其余车流考虑合并；
3. 调整初始方案：利用必要/充分条件，对长程车流**压缩**（压缩到站/发站，与短程合并）或**切割**（分割成多部分分别与短程合并），逐步寻找节省车小时最多的方案，直到无法取得更多节省；
4. 检查最优方案与各站改编能力，能力不足则改选，最终用式 11.10 计算方案值并画列车到达站图。

## 四、分组列车（摘录要点）

- 分组列车至少包含两个车组：到达列车终到站及其以远者为**基本车组**，到达终到站以近者为**补轴车组**。

# 术语表（两章速查）

> 定义均引自《铁路行车组织》（第 2 版）第四章、第十一章原文。带 ★ 者与调车作业计划编制直接相关。

## 第四章 调车工作

| 术语 | 定义（原文/要点） |
|---|---|
| 调车 | 除列车在车站到达、出发、通过以及在区间运行外，凡机车车辆所进行的一切有目的的移动统称为调车。 |
| 解体调车 | 将待解车列按重车的去向(到站)及空车车种分解到指定的线路上。 |
| 编组调车 | 按《技规》和列车编组计划的要求，将相应的车组(车辆)选编成车列。 |
| 摘挂调车 | 对列车摘减车组(减轴)、加挂车组(补轴)、换挂车组或摘挂车组。 |
| 取送调车 | 为货物装卸及车辆检修，向相应作业地点送车或取车。 |
| 调车钩 ★ | 机车连挂或摘解一组车辆的作业。调车作业计划的基本单位，故称「钩计划」。 |
| 连挂钩（挂车钩）★ | 表示机带车列中车辆数将增加的调车钩。 |
| 溜放钩（摘车钩）★ | 表示机带车列中车辆数将减少的调车钩。 |
| 调车程 ★ | 机车或机带车列(车辆)发生的一次有目的的调移，通常不改变运行方向。一个调车钩可分解为一个或几个调车程。 |
| 钩分 ★ | 单项作业时间标准，完成一个调车钩的平均分钟数，按钩的种类分别确定。 |
| 查标 | 用写实法查定调车作业时间标准的工作。 |
| 牵出线 ★ | 设在平道或不大于 2.5‰ 坡道上的调车设备，主要利用机车动力使车组积累动能后脱钩溜行。 |
| 推送调车法 | 用机车将车辆调移至适当地点，停稳后再摘车的调车方式。 |
| 溜放调车法 | 机车推送车列行进，达一定速度后使计划摘解的车组脱离车列自行溜出的调车方式。 |
| 多组溜放 | 机车推动车列加减速各一次，同时溜出几个车组的方式。 |
| 驼峰 | 以利用峰上车辆势能为主，也借助推峰动能而分解车列的调车设备，由推送部分、溜放部分和峰顶平台组成。 |
| 禁峰车 | 通过驼峰时可能危及作业和货物安全，禁止过峰的车辆。 |
| 禁溜车 | 禁止溜放、只允许机车推送下峰的车辆。 |
| 坐编 ★ | 将符合编组要求的大车组留在到发线上直接编组。坐编调车效率高。 |
| 按站顺编组 ★ | 列车中车组排列顺序按区段内中间站的顺序由近及远的顺序排列。 |
| 按到站成组编组 ★ | 车组顺序与中间站顺序可不一致，但同一到站的车辆必须紧密排在一起，不得分开。 |
| 下落 ★ | 把待编车列中的反顺序车组分解到调车表不同列的过程。 |
| 可调车组 ★ | 下落时可在两相邻列之间移动的车组；移动得当可形成邻组、节省溜放钩。 |
| 邻组 ★ | 两下落列合并后相邻、可一钩溜出去的相邻车组，可省一个溜放钩。 |
| 暂合列 ★ | 将两个或多个下落列合并在一起所形成的列。目的：减少挂车钩、减少线路数。 |
| 机前集结 ★ | 符合顺序要求的车组紧靠调机，分解时可以不溜去，以节省溜放钩。 |
| 调车作业通知单 ★ | 调车作业计划的形式，逐钩记录序、股道、甩挂、车号、备注。 |

## 第十一章 技术站列车编组计划的编制

| 术语 | 定义（原文/要点） |
|---|---|
| 列车编组计划 | 对技术站发出的各支车流，按照去向分别编组成不同到站、不同种类列车的计划。 |
| 技术站间车流表 | 由重车车流表经车流归并编制而成，是编制技术直达列车和直通列车的基础资料。 |
| 车流归并 | 由重车车流表到技术站间车流表的过程，按上、下行分别进行。 |
| 车流梯形图 | 表现各技术站间车流的图形资料，与车流表配套使用。 |
| 货车集结车小时 | 货车在集结过程中消耗的车小时；某支列流 `T集 = cm`，与吸收车流量无关。 |
| 无调中转车 | 只在到发线上进行到发技术作业即随原列车继续运行的货车。 |
| t节 | 货车在技术站无改编通过较之改编所节省的时间。 |
| 改编作业当量（r车） | 调机平均改编 1 辆货车（1 解 1 编计为 1 辆）所折合的车小时数。 |
| 列车到达站 | 列车编组计划中规定开行的某种列车的去向；将车流编入某去向列车称为编开某列车到达站。 |
| 同一支车流不拆散原则 | 不应当将同一支车流的车流量分离出来，分别与不同车流合并纳入不同列流。 |
| 车流接续归并原则 | 长程车流在技术站改编后成为该站发出车流的一部分，与该站相同到站车流合并开行。 |
| 支点站 | 分阶段计算法选出的主要编组站；选择条件是车流集散大、设备先进、变更重量标准点、自然分界点、枢纽站等。 |
| 绝对条件 ★ | 任何一支远程车流必须开行直达列流的条件（式 11.11），满足则一定开行。 |
| 必要条件 ★ | 车流单开（式 11.13）或合开（式 11.14）直达列流必须具备的前提，满足才可考虑。 |
| 充分条件 ★ | 长程车流不与某短程车流合并的条件；满足则不应合并。 |
| 超行区段 | 长程车流比短程车流多运行的那部分区段。 |
| 基本车组 / 补轴车组 | 分组列车中，到达终到站及其以远者为基本车组，到达终到站以近者为补轴车组。 |

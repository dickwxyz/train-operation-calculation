本目录是「调车作业计划智能体」的**教材知识库**，内容提炼自《铁路行车组织》（第 2 版）。

**前 3 篇的合并全文** `铁路行车组织第2版-前3篇.md`（`/qa` 的检索语料）。

## 用途

1. **给人和 Claude 阅读**：理解调车作业、按站顺编组「调车表法」的领域知识，改进求解器算法时有据可依（改动前请读 `调车工作/调车工作-算例集.md`）。
2. **RAG 参考**：应用内「教材问答」（`/api/qa`）的检索语料是教材**原文** `铁路行车组织第2版-前3篇.md`（见「与 RAG 的关系」）。

## 教材全文（前 3 篇）

`铁路行车组织第2版-前3篇.md` 是教材 PDF 第 11–279 页（印刷页 001–269）的合并 Markdown：
逐页经 `scripts/mineru_pdf_to_md.py` 解析，再由 `scripts/merge_textbook_md.py` 按页序拼接；
第四、十一章正文补自本目录两份原文 md，零散缺页（印刷页 058、125–126、170 下半、191）补自教材合订本。
全部插图统一放在 `前3篇-images/`（扫描页图 `p页码_`、第四章图 `ch4_`、第十一章图 `ch11_`）。
页与页之间用 HTML 注释标记「PDF 第 N 页 / 印刷页 NNN」，跨页段落和表格仍按页断开，属 OCR 固有局限。

## 阅读顺序建议

- 快速了解领域 → `调车工作/第四章-调车工作（提炼）.md` + `调车工作/调车工作-术语表.md`
- 理解/复现算法（下落列、可调车组、暂合方案、钩数）→ `调车工作/调车工作-算例集.md`（例4.3 优先）
- 对照原文 / 取习题原题 → `调车工作/铁路行车组织第2版-调车工作.md`

## 与 RAG 的关系

`/api/qa` 与 `/qa` 页面的检索语料就是本目录的 **`铁路行车组织第2版-前3篇.md`**（全书前 3 篇、带页标记）。
`scripts/rag/` 按「章/节/一、」结构切块并聚合到章节，用 **jieba/字二元组 BM25 + bge-m3 向量**
混合召回（numpy 索引），再由 DeepSeek 严格依据检索片段组织答案并标注章/节/印刷页。
索引生成在仓库根目录 `rag_index/`；模型在 `bge-m3/`（gitignored）。
两份章节原文 md、提炼、术语表、算例集仍供人工阅读与求解器回归，不重复进入检索索引，避免与全书正文重复命中。

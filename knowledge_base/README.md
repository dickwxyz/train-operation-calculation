# 知识库索引

本目录是「调车作业计划智能体」的**教材知识库**，内容提炼自《铁路行车组织》（第 2 版）的两章摘录（位于 `assets/`，检索语料即这两章原文）。

## 用途

1. **给人和 Claude 阅读**：理解调车作业、编组计划的领域知识，改进求解器算法时有据可依。
2. **作为 RAG 的辅助结构层**：应用内「教材问答」（`/api/qa`）的检索语料是 `assets/` 下的教材原文（保证回答可溯源、忠实于教材），本目录的提炼文件是其结构化导览。

## 文件说明

| 文件 | 内容 |
|---|---|
| `第四章-调车工作.md` | 第四章结构梳理 + 核心概念（调车分类、钩/程、牵出线/驼峰、钩计划、解体/编组计划、按站顺编组、下落→调整→合并） |
| `第十一章-编组计划编制.md` | 第十一章结构梳理 + 核心概念与公式（车流归并、集结车小时、无改编通过节省、绝对/必要/充分条件、表格计算法） |
| `术语表.md` | 两章术语 → 原文定义（速查） |
| `算法方法与代码对照.md` | 教材「调车表法」与 `shunting_plan.py`「分组选编法」的一致点与差异（改进算法前必读） |
| `算例集.md` | 例 4.1~4.6、例 11.1~11.6 的输入/输出要点 + 第四章综合题 1~15（现成题库） |

## 阅读顺序建议

- 快速了解领域 → `第四章-调车工作.md` + `术语表.md`
- 想改进求解器 → `算法方法与代码对照.md`（含代码当前缺什么、教材怎么做）
- 出题/演示 → `算例集.md`

## 与 RAG 的关系

`rag/corpus.py` 的检索语料是 `assets/` 下两章的**原始 Markdown**（原文分块，带章节出处）。问答流程：问题 → BM25 检索原文片段 → DeepSeek 依据片段生成回答。知识库的提炼文件不参与检索，避免与原文重复命中。

# 知识库索引

本目录是「调车作业计划智能体」的**教材知识库**，内容提炼自《铁路行车组织》（第 2 版）。
当前仅收录**第四章 调车工作**的结构化资料（位于 `调车工作/` 子目录）。第十一章相关的提炼与原文已移至 `过程/`（gitignored，见文末说明）。

## 用途

1. **给人和 Claude 阅读**：理解调车作业、按站顺编组「调车表法」的领域知识，改进求解器算法时有据可依（改动前请读 `调车工作/调车工作-算例集.md`）。
2. **RAG 参考**：应用内「教材问答」（`/api/qa`）的检索语料应为教材**原文**；第四章原文现存放于 `调车工作/铁路行车组织第2版-调车工作.md`（见「与 RAG 的关系」）。

## 阅读顺序建议

- 快速了解领域 → `调车工作/第四章-调车工作（提炼）.md` + `调车工作/调车工作-术语表.md`
- 理解/复现算法（下落列、可调车组、暂合方案、钩数）→ `调车工作/调车工作-算例集.md`（例4.3 优先）
- 对照原文 / 取习题原题 → `调车工作/铁路行车组织第2版-调车工作.md`

## 与 RAG 的关系

`rag/corpus.py` 的检索语料本应指向 `assets/` 下两章教材的**原始 Markdown**（原文分块、带出处）。
当前 **`assets/` 只含两章 PDF**，没有 md；第四章原文 md 实为 `knowledge_base/调车工作/铁路行车组织第2版-调车工作.md`，
第十一章原文 md 在 `过程/铁路行车组织第2版-技术站列车编组计划的编制/…md`。
因此 `/api/qa` 的语料路径目前失效、查询会报错（本次未修；需要时把 `rag/corpus.py` 的 `SOURCES` 改指上述两个真实文件即可）。
知识库的提炼文件不直接参与检索，避免与原文重复命中。
